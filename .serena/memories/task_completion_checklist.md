# タスク完了時のチェックリスト

コードの変更を完了した後、以下のステップを順番に実行してください。

## 1. コードフォーマット
```bash
make fmt
```
- `go fmt ./...` が実行される
- インポートの整理も行われる

## 2. 静的解析 (go vet)
```bash
make vet
```
- Go標準の静的解析ツール
- 潜在的なバグを検出

## 3. リンター実行
```bash
make lint
```
- golangci-lint を実行
- 全ての有効なリンターでチェック
- エラーがあれば修正

## 4. テスト実行
```bash
make test
```
- 全テストを実行
- 失敗があれば修正

## 5. 全チェック (推奨)
```bash
make check
```
- 上記1-4を一括実行 (fmt, vet, lint, test)
- CI/CDでの実行と同等

## オプション: カバレッジ確認
```bash
make test-coverage
```
- カバレッジレポート生成
- `coverage.html` をブラウザで確認可能

## オプション: レースコンディション検出
```bash
make test-race
```
- 並行処理のバグを検出

## 依存関係を変更した場合
```bash
make mod
```
- `go mod tidy` を実行
- go.mod と go.sum を整理

## 注意事項
- リンターエラーは全て修正すること
- テストは全てパスすること
- 新機能にはテストを追加すること
- カバレッジの低下に注意
